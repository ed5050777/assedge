Send instructions to Sam AI

  1. Replace all files in the existing extension folder and reload ASSEDGE.
  2. In Sam AI connection, paste the webhook token once and click Save token. It stays in local extension storage on this device across browser restarts and extension reloads. Clear token removes it. Disconnect only disconnects Google and clears CRM session data. A previously saved session token is migrated automatically when still available.
  3. Expand an asset, enter Instructions for Sam AI, and click Send to Sam AI.

The webhook uses the original endpoint and authentication header. It sends event_type=trigger, source=Assedge AppSheet, table=Assets, asset_id=the asset internal ID, objective=an empty string, and comment=the instructions. It does not modify the CRM sheet.

Only after a successful HTTP response are the instructions and saved draft cleared and Received by Sam AI displayed. This acknowledges receipt, not task completion. Failed requests retain the instructions, and no requests are retried automatically. Your computer must be able to reach the configured HTTPS/Tailscale endpoint.

The token is saved locally, not synced through Chrome or included in the extension package. Local extension storage is not an encrypted password vault; access is restricted to trusted extension contexts.

Version 1.4.2 sends tasks through the extension service worker and checks that host permission is granted before sending. The panel never fetches the webhook directly. If the gateway requires a cryptographic signature rather than X-Gitlab-Token, the gateway authentication must be aligned separately; no signature scheme is guessed. A 401 or 403 response is shown as an authentication error.
