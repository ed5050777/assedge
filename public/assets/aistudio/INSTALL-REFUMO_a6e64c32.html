ASSEDGE for Refumo

Google configuration: project assedge-refumo, Internal audience in the atara-consulting.com Workspace organization, managed using eyal@refumo.com. Google Sheets API is enabled. The CRM sheet remains the existing linked sheet.

  1. Open a Chrome profile signed in as your Refumo Workspace account. This matters because the extension uses Chrome’s Google identity for authorization.
  2. Extract ASSEDGE-Refumo.zip into a permanent folder.
  3. Open chrome://extensions, enable Developer mode, click Load unpacked and select the assedge-refumo folder containing manifest.json.
  4. Verify the ID shown is kajdbkjagnimidbkjoladfmglkakegim. The included public manifest key keeps this ID consistent across local installations. Keep it in future updates.
  5. Pin ASSEDGE, open its panel, then press Search to complete Google sign-in if requested. Approve the read-only Sheets request yourself.
  6. For Sam AI, use Settings to save the administrator-provided assedge webhook token on each authorized device. No webhook token or private key is included in this package. Verify the token through Check saved token. The computer must be able to reach the Hermes endpoint.

Use this Refumo package in a separate folder/profile from the Deissi version. Its Google client and extension identity differ. Each user still needs CRM and linked-file access. Install once per user/device; you do not need to create another OAuth client for every installation with this manifest key.

The Cloud setup is prepared; live OAuth consent, extension installation and Sam AI delivery must be verified in the Refumo browser profile. Organization policy may require an admin approval when the first user signs in. Future Chrome Web Store publishing may require a different registered extension ID.
